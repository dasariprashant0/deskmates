# deskmates

A local app that shows your live Claude Code sessions as a pixel-art office.

Status: under construction (v0.1 in progress). Nothing is published. Local only: it reads transcripts on your machine and sends nothing anywhere.

Docs: `docs/ARCHITECTURE.md`, `docs/SECURITY.md`, `docs/DESIGN.md`, `docs/ROADMAP.md`, `docs/TOOLKIT.md`, plan in `docs/superpowers/plans/`.
