# deskmates threat model

Status: draft v0.1, from the `agentic-council:Skeptic` agent's review. Design level only, no code was inspected. S = severity (C critical, H high, M medium).

| # | Risk | Failure scenario | S | Mitigation | Test |
|---|---|---|---|---|---|
| 1 | Browser reaches the allow/deny endpoint (CSRF, DNS rebinding, cross-origin WebSocket) | A malicious page POSTs to `localhost` or rebinds a hostname to 127.0.0.1 or opens a WebSocket and approves a dangerous command: remote code execution through the user's own agent | C | Bind 127.0.0.1 only. Reject any Host not exactly `localhost:PORT` or `127.0.0.1:PORT`. Check Origin on every HTTP and WS upgrade. Require a random per-run token in a custom header or WS subprotocol; no cookies. JSON only. Serve the token only to the same-origin page | Spoofed Host, `Origin: https://evil.com`, missing token, form-encoded POST must all fail; run a real rebinding harness |
| 2 | Approve/deny races and stale entries | Approval after the request timed out lands on the next request; double click sends two decisions; approval after Stop | H | Server-generated unique request id; state machine pending/decided/expired/superseded; atomic compare-and-set; bind decision to id plus hash of tool input; hook timeout shorter than Claude's; expiry means no decision (terminal prompt), never default allow | Decide twice, after timeout, after the agent moved on; two simultaneous requests; kill deskmates mid-request and confirm the terminal still prompts |
| 3 | Hook trust and fail-open or fail-closed | Writable hook script replaced by a repo; hung daemon blocks agents; a deny from deskmates overrides the user's own rules | H | Install script in a user-owned dir, mode 0700, record its hash. ## What is most likely to make this fail

1. A security incident around the approve button. Ship passive and read-only first; add approve only after the token, Host and Origin checks pass the rebinding test.
2. Transcript format churn: a permanent maintenance tax. Tolerant parsing, fixtures, a "degraded" badge.
3. The wow factor wearing off. The Needs-you queue must be clearly faster than glancing at the terminal, which needs reliable notifications, which needs hooks, trust and consent.
4. Scope sprawl: replay, export, redaction, providers, team mode and approvals are separate products. Redaction alone is never finished. Sequence them (see `ROADMAP.md`).
5. Platform overlap: Anthropic or existing viewers may ship the same thing. Keep it small, fast and personal.

## Non-negotiables

- No state-changing endpoint without a per-run secret plus Host and Origin validation, tested against a real DNS-rebinding harness.
- Nothing is installed into the user's settings without a shown diff and explicit consent.
- No transcript content leaves the machine.

## What the v0.1 server implements (read-only surface)

The v0.1 server exposes no state-changing endpoint. What exists, and how it was verified:

- Loopback only: it binds `127.0.0.1` and refuses any other `host` (`host-not-allowed`). No LAN mode.
- Every HTTP request: exact `Host` (`localhost:PORT` or `127.0.0.1:PORT`, one header only), method GET or HEAD only (else 405), exact `Origin` when present, and `Sec-Fetch-Site: cross-site` refused. No CORS headers, no cookies.
- Static shell: `/` and the app assets are public (they contain no data and the page cannot attach a token to relative asset requests). Path handling resists traversal, encodings, NUL, dotfiles, symlinks and FIFOs. Case-variant paths such as `/APP.JS` resolve to the same public asset on case-insensitive filesystems (macOS default); that exposes nothing extra.
- Token: at least 32 characters from `[A-Za-z0-9_-]`, compared in constant time. It travels in the URL fragment of the launch link (`http://127.0.0.1:PORT/#t=TOKEN`), which browsers never send to the server, never put in `Referer`, and which the page script should clear with `history.replaceState`. It is presented to the WebSocket as the second `Sec-WebSocket-Protocol` entry after `deskmates.v1`, and to `/api/status` as `Authorization: Bearer`. A query-string token is never accepted.
- WebSocket: upgrade checks Host, Origin and token before upgrading; limits on clients, message size, queue and slow readers; heartbeat; at most 5 `resync` per second per client; only `resync` is honored.
- Privacy: snapshots and event frames replace the home directory with `~`; `tool_result` bodies are never carried; `/api/status` carries counts and error codes only.
- Card data: `AgentState` carries `recent` (at most 5 labels: tool name plus a restricted summary, tool name only for Grep, Glob, Agent and Task) and `contextTokens` (a number). Labels are redacted server-side on every send path and rendered with `textContent` only.
- Verified by: the Node test suite (337 server tests), an independent live attack run of about 110 attacks (Host, Origin, subprotocol, traversal, smuggling, WebSocket abuse, timeouts, leaks; no critical or high findings), and a design review against this document.

### Known limits and conditions for v0.2 (approve and deny)

- No real-browser DNS-rebinding harness exists yet. A rebound request always carries the attacker's hostname in `Host`, which the tests send, but the non-negotiable asks for a real-browser harness before any state-changing endpoint ships.
- Before v0.2 adds approve and deny: use a separate decide capability and secret (not the read token), require a present same-origin `Origin` and a user gesture, show the raw command from the hook payload, and implement the request state machine, timeouts and race tests from risks 2, 3, 4 and 13.
- The first attack runs used Bun; on 2026-10-18 the live attack script `scripts/attack.mjs` (237 attacks) was re-run under Node v26.10.0 against the built CLI: 237 pass, 0 fail, no findings. Re-run it (`node scripts/attack.mjs`) before each public release.
- Any other process on the same machine can connect if it has the token; the token is the only protection against local users.
- The launch URL, including the token in its fragment, is passed as an argument to the browser opener (`open`, `xdg-open`, `cmd /c start`). Other local users on the same machine can read it in `ps` while the opener process lives (usually well under a second, but a slow browser start can stretch it). Mitigation, a one-time nonce exchanged for the token over the loopback socket, is deferred to v0.2.
- Dependencies are not changed by the review fixes. CI and release builds must install with `pnpm install --frozen-lockfile` so the lockfile is the only source of resolved versions (`.github/workflows/ci.yml` already does).
